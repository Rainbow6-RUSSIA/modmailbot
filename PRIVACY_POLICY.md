# Политика конфиденциальности Modmail

## О боте
Modmail — система обращений, которая позволяет пользователям связаться с командой сервера через бота, не отправляя личные сообщения отдельным модераторам и не упоминая их публично на сервере.

Исходный код бота доступен по адресу: https://github.com/Rainbow6-RUSSIA/modmailbot (форк https://github.com/Dragory/modmailbot)

## Хранимые персональные данные
Бот хранит полные транскрипты тредов Modmail. Транскрипты содержат:
* ID пользователя, имя пользователя, никнейм и отображаемое имя пользователя, который обратился или к которому обратились
* ID пользователя, имя пользователя, никнейм и отображаемое имя модераторов, участвовавших в треде

Кроме того, бот хранит:
* ID и имя пользователей, которым заблокирована возможность писать боту
* ID автора и ID пользователя, к которому относится заметка, сохранённая в боте
* ID автора сниппетов, сохранённых в боте

## Срок хранения данных
* Транскрипты тредов хранятся до их удаления вручную
* ID пользователей, связанные с заметками, хранятся до удаления заметки
* ID пользователей, связанные со сниппетами, хранятся до удаления сниппета

## Запросы на доступ к данным и их удаление
Чтобы запросить доступ к своим данным или их удаление, напишите на: [admin@rainbow6.ru](mailto:admin@rainbow6.ru)

# Modmail privacy policy

## Bot overview
Modmail is a ticketing system that lets users contact server staff through the bot instead of messaging staff members individually or pinging them publicly in the server.

The bot's source code is available at: https://github.com/Rainbow6-RUSSIA/modmailbot (a fork of https://github.com/Dragory/modmailbot)

## Stored personal data
The bot stores full transcripts of modmail threads. These transcripts include:
* User ID, username, nickname, and display name of the contacting or contacted user
* User ID, username, nickname, and display name of any moderators participating in the thread

In addition, the bot stores:
* User ID and username of users blocked from contacting the bot
* User ID of author and target user of notes saved in the bot
* User ID of the author of snippets saved in the bot

## Data retention
* Thread transcripts are stored until manually deleted
* User IDs tied to notes are stored until the note is deleted
* User IDs tied to snippets are stored until the snippet is deleted

## Data access and deletion requests
To request access to your data or for your data to be deleted, please contact: [admin@rainbow6.ru](mailto:admin@rainbow6.ru)
