# Политика конфиденциальности Modmail

## О боте
Modmail — система обращений, которая позволяет пользователям связаться с командой сервера через бота, не отправляя личные сообщения отдельным модераторам и не упоминая их публично на сервере.

Исходный код бота доступен по адресу: https://github.com/Rainbow6-RUSSIA/modmailbot (форк https://github.com/Dragory/modmailbot)

## Хранимые персональные данные
Бот хранит полные транскрипты тредов Modmail. Транскрипты содержат:
* ID пользователя, имя пользователя, никнейм и отображаемое имя пользователя, который обратился или к которому обратились
* ID пользователя, имя пользователя, никнейм и отображаемое имя модераторов, участвовавших в треде

Кроме того, бот хранит:
* ID и имя пользователей, которым заблокирована возможность писать боту
* ID автора и ID пользователя, к которому относится заметка, сохранённая в боте
* ID автора сниппетов, сохранённых в боте

## Срок хранения данных
* Транскрипты тредов хранятся до их удаления вручную
* ID пользователей, связанные с заметками, хранятся до удаления заметки
* ID пользователей, связанные со сниппетами, хранятся до удаления сниппета
